# d2-webgpu

Docs: [project record](docs/PROJECT.md) (origins, process, architecture, tests, limitations) · [plan](docs/PLAN.md)

Diablo II: Lord of Destruction (1.14d) in the browser with a WebGPU renderer.
Engine logic and file formats come from [d2decomped](https://github.com/psi29a/d2decomped)
(submodule in `third_party/`), compiled to WebAssembly. Plan: [docs/PLAN.md](docs/PLAN.md).

**No Blizzard data is included.** You pick your own Diablo II installation (MPQ files) in the browser; files never leave your machine.
